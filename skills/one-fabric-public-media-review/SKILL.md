# ©️8x8 One Fabric · Public Studio Media Review

Canonical root: fabric://8x8/core. Target: isolated public User Edition; never the owner-private control plane.

## Working contract

1. Open the public User Edition at /studio and ask the user to select an owned or authorized local media file with the system chooser.
2. Verify the file can actually play or decode. Read its filename, MIME, size, source label, and, when available, the 32 MiB-bounded SHA-256. A file larger than the hash limit must remain NOT_HASHED_SIZE_GATED.
3. Review visible frames, audio and captions **only if those contents are actually accessible**. Metadata alone is not a transcript and a social link alone is not a decoded video.
4. Compare documented capability leads with the existing 8x8 capability federation. Classify as PAST_PRESERVED, PRESENT_PROVEN or FUTURE_GATED; do not infer a live integration from a screenshot, repository name or promotional post.
5. When an actual MCP or A2A broker is authorized and callable, use its precise tenant-scoped read tools and demand a response receipt. STAGED is not DELIVERED and tool discovery is not execution.
6. Preserve URL, authorship, license, media hashes, version, observed behavior, evidence timestamp and exact test denominator. Route implementation proposals for review, tests and reversible promotion.
7. Never collect private credentials in chat, request a device STOP override, open external URLs through an untrusted content-discovery bypass, publish copyrighted media, or broaden tenant scopes.
8. Model/council consensus cannot replace a user or provider's required authorization for high-impact effects.

## Exact current public capability

/studio supports local image/video/audio preview, bounded metadata/SHA-256 receipts, and exporting a single real video frame from a decoded video. It does **not** provide remote transcription, automated content access, external social harvesting, full-motion AI scene extraction, or proof that public ChatGPT MCP images render. The Studio source must be independently deployed before calling it available on a public URL.

## Acceptance

Prove local unit tests, deployed route and CSP, browser and Android picker behavior, plus accessible receipts separately. For a native ChatGPT plugin, verify OAuth discovery, RS256 claims, JWKS, scope, tenant isolation and an independently rendered image. Do not advertise public plugin installation until its directory/connection approval is confirmed.

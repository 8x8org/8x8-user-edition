# MSG197 Research Council Protocol

## Purpose

The council compares independent assessments of the same thirteen immutable upstream pins. It does not manufacture consensus, install candidates or grant runtime authority.

## Admission

A valid vote requires a verified canonical agent identity, an active bounded lease, the exact input pin-set digest, a machine-readable recommendation set, security vetoes, an output digest and a completion receipt. Missing identity or lease means the submission is advisory only or rejected.

## Quorum and veto

Four valid votes are required from the six named participant classes. A substantiated security veto blocks adoption regardless of simple majority. FlashTM8 remains the final owner authority.

## Disagreement

Conflicting recommendations are preserved. The reconciliation report must identify whether disagreement comes from different evidence, stale context, different risk tolerance or incompatible assumptions. It cannot average away a safety objection.

## Current state

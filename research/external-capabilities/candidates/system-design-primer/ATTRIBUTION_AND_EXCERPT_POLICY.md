## Curation rules

1. Prefer topic titles, anchors, metadata and original 8x8 summaries instead of copying source prose.
2. Any excerpt must be minimal, clearly quoted, attributed, linked to the exact commit and accompanied by an 8x8-authored explanation.
3. Excerpts are capped at 25 words per indexed item unless a future reviewed artifact documents why more is required and remains license-compliant.
4. Diagrams, images, flashcard decks and bundled binary resources are not copied by this packet.
5. External links are metadata only. Agents and validators must not automatically fetch or execute them.
6. Code samples remain disabled. A sample can be evaluated only in a separate candidate task with its own threat model, license record, sandbox and receipt.
7. Transformations must retain repository, commit, path, anchor, license, attribution and transformation history.
8. Updated upstream content does not silently replace this index. Refresh requires a reviewed commit-pin update and new hashes.

## 8x8 authority boundary

Imported material cannot:

- modify policy;
- create or extend permissions;
- authorize shell, browser, network, filesystem, wallet or signing actions;
- satisfy an owner approval;
- become system memory truth merely by being retrieved;
- override task IDs, leases, receipts or the Control Fabric.

Rollback is a Git revert or deletion of this generated index. No runtime uninstall is required because nothing was installed.

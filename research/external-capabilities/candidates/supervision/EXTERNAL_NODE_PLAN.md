# MSG197-VISION-001 Supervision External-Node Plan

## Verdict

`NARROW_SUBSET_EXTERNAL_NODE_ONLY`

Supervision is a broad computer-vision utility toolkit, not a model by itself. The useful 8x8 surface is a narrow set of model-agnostic data structures, annotations, dataset conversion, zones and tracking utilities.

## First-pass boundary

The first benchmark must install the exact source pin in a disposable external Linux environment and perform an import plus synthetic-array utility test. It must not download a model, use a Roboflow API key, read private media, access a camera or microphone, or enable optional model connectors.

## Resource and supply-chain evidence

Before installation, the canary must inventory wheels and dependency bytes. It must record Python, platform, package hashes, SBOM, vulnerabilities, install time, import latency, peak RAM, disk growth and cleanup residuals. Native-wheel failures are evidence, not invitations to compile half the scientific Python ecosystem on the Samsung.

## Adapter boundary

A future adapter may receive synthetic or owner-approved media references and return typed detections or annotated artifact references. It cannot publish media, identify people, invoke models, access devices or alter canonical memory without separate capability gates.

## Completion boundary

This static plan does not complete Issue #51. The issue remains open until an external-node no-model benchmark and cleanup proof exist.

# MSG197-SKILLS-001 Capability Mapping

## Verdict

`ADOPT_SELECTED_WORKFLOW_SCHEMAS_NOT_SKILL_EXECUTION`

The repository provides a useful vocabulary for the software lifecycle and emphasizes specification, small plans, testing, review and measured shipping. Those ideas map cleanly onto existing 8x8 task packets, leases, evidence gates, Guardian review and progressive release.

## Conflict boundary

The source also describes automatic activation, broad multi-agent installation and an approved-pass autonomous build mode. Those mechanisms cannot become 8x8 authority. Imported skill text is untrusted reference data. It cannot register tools, expand permissions, select credentials, authorize network access or bypass owner gates.

## Mapping

The static manifest maps the observed lifecycle to canonical 8x8 capabilities. Unknown commands and undeclared permissions fail closed. The future parser can emit a proposed capability request, never an executable tool binding.

## Decision

The workflow vocabulary is accepted as reference material. Installation, automatic discovery and direct execution are rejected. A separate no-execution parser canary must prove hidden instructions remain inert and every permission difference is explicit.

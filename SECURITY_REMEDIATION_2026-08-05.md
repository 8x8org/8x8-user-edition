# Public Boundary Remediation, 2026-08-05

## Incident

Detailed private research and operational context was mistakenly projected into the public User Edition through issues, comments and source files.

## Current-branch remediation

This release:

- removes the detailed external-capability research tree from the current public branch;
- removes the capabilities observatory that rendered private research-state details;
- removes the disabled private adapter projection;
- removes the detailed product-surface matrix that named private infrastructure and repositories;
- restores the public product tree to the last pre-projection state;
- adds a Three-Reality public-information boundary;
- adds fail-closed CI checks for private paths, topology, internal coordinator identity, protected deployment identifiers and credential-shaped material.

## Residual risk

Git history, pull-request discussions, issue edit history, forks, clones or third-party caches may retain earlier revisions. This commit does not rewrite public Git history. Any actual credential discovered during follow-up review must be rotated immediately; no raw credential value is asserted by this document.

## Required follow-up

- review historical public metadata and cached artifacts;
- rotate any secret or identifier found to have been exposed;
- keep complete repository census and integration plans in private governance;
- project only allowlisted public fields after independent review;
- require the boundary workflow on every future public release.

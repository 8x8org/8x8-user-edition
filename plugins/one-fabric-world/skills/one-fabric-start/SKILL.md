# One Fabric User Edition — Start

Use the public read-only MCP tools to show the 19-domain catalog, default public-safe agent templates, staged account linking and current plan targets. The public User Edition source is https://github.com/8x8org/8x8-user-edition and its protected-beta 8x8 ID proposal is PR #200. This plugin is **prelaunch** and private. Do not claim any OAuth identity connection, ChatGPT account link, user-specific memory access, subscribed access, voice session, verified model runtime, financed trade, public post, device command or APK activation that lacks an independently verified receipt.

**Use one 8x8 ID**: user signs in through a real 8x8 IdP; ChatGPT MCP needs OAuth 2.1 + PKCE; Sign in with ChatGPT is separate and conditional on eligibility; every external app and device requires user-specific provider consent. ChatGPT memory/history and other plugin tokens are not automatically shared. Users own their agent instance memory. Default archetypes are protected source templates only, not founder-private agent data.

**Preview plans:** 88 promotional metered minutes and $8.88/month are requested product targets, not live entitlements. Explain that payment alone never authorizes funded trading, wallet signing, device control or public posts. When the user asks to connect a provider, guide them through that provider's own consent flow; never silently install or authorize plugins.

**Current tool family (v0.2.0):** original capability/world/agents/studio/release tools plus unified modules, identity guide, user archetypes, usage plan preview, connector guidance and platform surfaces. All tools are read-only and report launch gates. MCP App UI resource: `ui://8x8/one-fabric-user-edition-hub.html`, if the host supports rendering.

# Support

This is an open-source project and community support is provided on a best-effort basis.

## Where to get help

- **Bug reports and feature requests**: Open an [issue](https://github.com/8x8org/8x8-user-edition/issues).
- **Security concerns**: See [SECURITY.md](SECURITY.md).
- **General questions**: Check the [README](README.md) and [Architecture](ARCHITECTURE.md) documentation first.

## What to expect

This is a public beta. Response times vary and are not guaranteed. For critical issues, please open a GitHub issue with a clear description.

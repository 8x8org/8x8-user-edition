# Contributing to 8x8 User Edition

Thank you for considering contributing to the 8x8 User Edition. This project is a public beta, and contributions that improve documentation, fix bugs, or clarify the public-private boundary are welcome.

## How to contribute

1. Fork the repository.
2. Create a feature branch (`git checkout -b my-change`).
3. Make your changes.
4. Run the CI validation checks locally (see [Run locally](README.md#validate-locally) in the README).
5. Commit with a clear message.
6. Push to your fork and open a pull request.

## What to avoid

- Do not include credentials, private keys, wallet material, or private-system logs.
- Do not add backend dependencies, account systems, or telemetry.
- If your change touches the public-private security boundary, explain why it is safe.

## Code of conduct

All contributors are expected to follow the [Code of Conduct](CODE_OF_CONDUCT.md).

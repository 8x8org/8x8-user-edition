# Public Information Boundary

The 8x8 User Edition is a public product repository. It contains only information and software intentionally approved for public use.

## Three-reality publication model

1. **Private Past** contains private history, internal operations, private infrastructure, raw evidence, memories, experiments and recovery material.
2. **Future Lab** contains private research, candidate integrations, councils, adapters, simulations and canaries that have not completed public release gates.
3. **Public Present** contains only independently reviewed, privacy-safe release units with public provenance, tests, rollback evidence and explicit publication approval.

Nothing moves directly from Private Past or Future Lab into Public Present.

## Never publish here

- private infrastructure, device or runtime topology;
- private repository or workspace inventory;
- internal agent rosters, leases, memory, messages or operational receipts;
- credentials, tokens, private account data, wallet material or signing authority;
- private paths, logs, database details, protected deployment identifiers or administrative routes;
- unpublished security findings, incident details or recovery procedures;
- private connector configuration, communications or personal data.

## Promotion contract

A public release unit must provide:

- an explicit public scope;
- a source and license record;
- privacy, security and accessibility checks;
- deterministic tests;
- a public-safe data fixture or approved public data source;
- a rollback target;
- an exact release receipt;
- owner publication approval.

Private details may be summarized only as neutral public claims such as `not connected`, `not available`, `planned`, or `not included`. Public diagrams and dashboards must never imitate live telemetry unless the displayed data is bound to a public receipt.

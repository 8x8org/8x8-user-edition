# Public Capabilities

This repository contains public, least-authority 8x8 User Edition release units.

Public capabilities may include:

- privacy-safe interfaces and static demonstrations;
- public schemas, plugin contracts and developer examples;
- public agent archetypes and educational content;
- public maps or simulations using synthetic or consented data;
- public provenance, accessibility and release evidence.

Detailed internal research, private runtime state, agent operations, repository census, connector configuration and implementation backlog are not published here. Candidate capabilities remain private until they complete the public promotion contract in `PUBLIC_INFORMATION_BOUNDARY.md`.

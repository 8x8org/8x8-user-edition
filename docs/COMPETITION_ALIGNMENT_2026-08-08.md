# Competition Alignment — 2026-08-08

This document treats competition success as a product-quality target, never a guaranteed outcome.

## OpenAI Build Week

Current official OpenAI criteria emphasize:
- technical implementation;
- design and user experience;
- potential impact;
- quality of the idea;
- thoughtful use of GPT-5.6 and Codex;
- a clear problem / solution / approach story.

For 8x8, the strongest judge-facing projection is not the entire historical estate. It is a concise proof that the public 0.0.1 Beta is a real operating layer over an evidence-governed agent Fabric: opening Gate -> identity/readiness -> Reality Graph -> agent/mission execution -> receipts/provenance -> adaptive world/Studio experience.

## Build with Gemini XPRIZE

Current official rules require a newly created AI-operated business during the submission period, at least one Google Cloud product, and at least one Gemini API call in deployed LLM functionality. Pre-existing generic frameworks/templates/code may be reused only with clear disclosure. The submission requires a working product/test path, a demo video under three minutes, code access for judges, user evidence, revenue/expense evidence, and production-operation evidence. Stage Two equally weights:
- Business Viability;
- AI-Native Operations;
- Category Impact.

Therefore the XPRIZE-facing 8x8 layer must be a clearly defined newly created business/product built during the eligible period, with explicit lineage disclosure to the pre-existing 8x8 OS. The submission should not falsely represent older 8x8 history as newly created.

## Release priorities that improve both competitions and the larger 8x8 roadmap

1. Real account/profile/permanent 8x8 ID backend and protected beta onboarding.
2. Judge-safe test account and reproducible First Blink flow.
3. One compelling AI-native workflow that visibly executes end-to-end and produces an evidence receipt.
4. Live Reality/Proof Graph state sourced from actual services rather than hard-coded display values.
5. Strong spatial UX: Gate, world navigation, agent civilization, graph, Studio and mission surfaces.
6. Mobile performance and accessibility certification.
7. Production observability, rollback, provenance and continuous health.
8. For XPRIZE specifically: real Google Cloud use + deployed Gemini call, real user evidence, truthful revenue/expense evidence, production logs, and explicit pre-existing-work disclosure.
9. A sub-three-minute demo whose first 20 seconds communicate the problem, product and proof.
10. Never sacrifice security or truthful state to make competition screenshots look stronger.

## Non-goals

- No claim of winning before judges decide.
- No fabricated 88k active-user count, revenue, uptime, model count or operational telemetry.
- No mainnet token/NFT/wallet authority inherited from a visual design.
- No hidden reuse of historical 8x8 work in XPRIZE lineage.

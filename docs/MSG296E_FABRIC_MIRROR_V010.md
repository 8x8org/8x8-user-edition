# MSG296E — 8x8 Fabric Mirror v0.1.0

Status: `SOURCE_CANDIDATE / PUBLIC_SAFE / DEPLOYMENT_VERIFICATION_REQUIRED`

## Why this rebuild exists

The earlier v0.0.8/v0.0.9 slices did not represent the accumulated 8x8 estate and the linked Vercel production project was observed serving a TypeScript source file at `/` with MIME `video/mp2t`, which caused mobile browsers to download/handle a file instead of rendering the interface. v0.1.0 therefore treats routing correctness and whole-system reconciliation as release requirements, not decorative follow-ups.

## Public/private boundary

Never publish owner credentials or private keys, wallet signing/recovery material, private repository contents, unrestricted raw messages/memory/logs, sensitive device topology or exact private locations, privileged control channels, or live financial execution authority.

The public interface may show sanitized aggregate states and explicit VERIFIED / PARTIAL / PLANNED / BLOCKED labels.

## Research-backed implementation direction

Candidates to evaluate in bounded canaries include OpenTelemetry for traces/metrics/logs and GenAI semantics, CloudEvents-style event envelopes, W3C PROV lineage, A2A/MCP interoperability, Cytoscape-style graph semantic zoom, WebGPU/WebXR for advanced spatial presentation, Cesium for planetary projection, C2PA for Studio/media provenance, TUF/Sigstore/SLSA for release integrity, CRDT/local-first patterns for non-authoritative collaborative UI state, and durable workflow/replay patterns for long-running missions. None is declared integrated merely because it is modern.

## Deployment acceptance contract

A public release is not PASS until all of the following are demonstrated on the exact reviewed commit:

1. `/`, `/first-blink`, `/world`, and `/art-board` return HTTP 200 browser-renderable HTML;
2. `Content-Type` is `text/html` for route documents;
3. no `Content-Disposition: attachment` is emitted;
4. the response body is HTML, never TypeScript/JavaScript source accidentally selected as the root artifact;
5. logged-out access works without preview authentication for the public alias;
6. Android Chromium smoke passes;
7. iPhone/mobile Safari smoke passes;
8. security headers and public-information-boundary checks pass;
9. no private topology or secret material is present;
10. rollback target and exact-head deployment receipt are recorded.

## Repository convergence truth

Sixteen connected repositories are currently visible to the connected GitHub account: five public and eleven protected/private. This release does not claim that every file in all sixteen has already been semantically reconciled. File-level reconciliation remains an evidence-bearing mission that should classify historical material as `KEEP`, `MERGE`, `REWRITE`, `ARCHIVE`, `QUARANTINE`, `DELETE_CANDIDATE`, or `UNKNOWN` before migration.

## Release truth

v0.1.0 is a materially broader public-safe whole-system mirror. It is not evidence that the entire private 8x8 estate, full fleet, local voice loop, every historical artifact, mainnet economy, or every Future Lab capability is already production complete.

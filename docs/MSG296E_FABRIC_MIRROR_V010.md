## Why this rebuild exists

The earlier v0.0.8/v0.0.9 slices did not represent the accumulated 8x8 estate and the linked historical deployment was observed serving a source artifact at `/` instead of browser-renderable HTML on mobile. v0.1.1 therefore treats routing correctness, public-boundary safety and whole-system reconciliation as release requirements.

## First Blink v0.1.1

The public demo visualizes the contract:

`CALLER_IDENTITY -> AUTHORITY -> SERAPHIM -> LATEST_GOOD_SNAPSHOT -> THREE_REALITIES -> ACTIVE_MISSION_DAG -> MEMORY/EVIDENCE -> MODEL_FABRIC -> TOOLS/CONNECTORS -> CONTEXT_BOOTSTRAP_RECEIPT`

Repeated public-demo runs are serialized: a previous interval is cancelled before a new run starts, and the trigger is disabled until completion. The browser demo is deliberately public-safe and does not fetch private runtime data. Universal runtime certification across every client/agent remains a separate evidence gate.

## Public/private boundary

Never publish owner credentials or private keys, wallet signing/recovery material, protected repository inventory, unrestricted raw messages/memory/logs, sensitive device topology or exact private locations, privileged control channels, or live financial execution authority.

The public interface may show sanitized public repository references, aggregate capability states and explicit VERIFIED / PARTIAL / PLANNED / BLOCKED labels.

## Research-backed implementation direction

Candidates to evaluate in bounded canaries include OpenTelemetry for traces/metrics/logs and GenAI semantics, CloudEvents-style event envelopes, W3C PROV lineage, A2A/MCP interoperability, graph semantic zoom, WebGPU/WebXR for advanced spatial presentation, Cesium-class planetary projection, C2PA for Studio/media provenance, TUF/Sigstore/SLSA for release integrity, CRDT/local-first patterns for non-authoritative collaborative UI state, and durable workflow/replay patterns for long-running missions. None is declared integrated merely because it is modern.

## Deployment acceptance contract

A public release is not PASS until all of the following are demonstrated on the exact reviewed commit:

1. `/`, `/first-blink`, `/world`, and `/art-board` return HTTP 200 browser-renderable HTML;
2. `Content-Type` is `text/html` for route documents;
3. no `Content-Disposition: attachment` is emitted;
4. the response body is HTML, never an accidentally selected source artifact;
5. logged-out access works without preview authentication for the public alias;
6. Android Chromium smoke passes;
7. iPhone/mobile Safari smoke passes;
8. security headers and public-information-boundary checks pass;
9. no private topology, protected inventory counts or secret material is present;
10. rollback target and exact-head deployment receipt are recorded.

## Repository convergence truth

Public repositories are named only where already intentionally public. Additional protected lineage is acknowledged without exposing counts, names or contents. File-level reconciliation remains an evidence-bearing mission that should classify historical material as `KEEP`, `MERGE`, `REWRITE`, `ARCHIVE`, `QUARANTINE`, `DELETE_CANDIDATE`, or `UNKNOWN` before migration.

## Release truth

v0.1.1 is a materially broader public-safe whole-system mirror. It is not evidence that the entire private 8x8 estate, full fleet, local voice loop, every historical artifact, mainnet economy, or every Future Lab capability is already production complete.

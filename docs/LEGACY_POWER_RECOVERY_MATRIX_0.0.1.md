## Historical deployment warning

The separately deployed `8x8-ecosystem` historical carrier contains materially broader interface ideas than the current public Atlas, including Three.js spatial navigation, world maps, voice UI, wallet/economy panels, trading charts, streaming, games, terminal patterns, live-log concepts, and device telemetry surfaces.

It also contains stale or unsafe public claims and implementation assumptions, including product maturity drift, hard-coded wallet addresses, simulated fleet counts, historical backend URLs, local service URLs, token/NFT price and yield language, and UI states that imply live functionality without current evidence.

Therefore it is a valuable archaeological source, not a valid production truth source.

## Recovery rule

For every recovered feature:

1. identify exact source file/commit;
2. hash the source;
3. classify sensitivity and Reality;
4. determine whether the capability is still desired;
5. rewrite against current 0.0.1 contracts rather than copying stale state;
6. remove credentials, addresses, fake metrics, private topology and obsolete version claims;
7. add tests and accessibility/security coverage;
8. create a Proof Graph receipt;
9. deploy through current canonical release train;
10. only then supersede the historical branch or carrier.

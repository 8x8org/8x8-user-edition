## User goal

Someone searching for 8x8, AI agents, models, Planet Earth, climate, forests, animals, research, solar energy, nuclear-energy education, films, finance, education or a newly discovered discipline should be able to learn what ©️8x8 works on, identify useful credible sources, and reach genuinely released tools where such tools are independently available. The aspiration to represent all human, animal, ecological, scientific, linguistic and future subjects is an *open-world indexing goal*, not a statement that 8x8 knows or operates all of them today.

The existing Three-Gate World is the intended common experience. The first public-safe source slice is `projects/world-atlas/index.html` with `projects/world-atlas/subject-atlas.v1.json`: **eight curated realms and 64 seed topics**. An accessible 2D directory, not a live geospatial globe or authenticated 3D multiplayer service. This source is automatically copied by the existing Vercel static build because `scripts/build-vercel-static.mjs` already copies the entire `projects` tree. The current public Projects entry links to it. Publication and indexing await a verified actual deployment.

## Public taxonomy contract, extensible not misleading

Use the One Fabric capability registry and provenance graph, rather than a second knowledge authority. Every discoverable entry carries a typed ID, category, versioned alias/synonyms in appropriate languages, source/citation, safe public/private visibility, time freshness, region/jurisdiction where material, and one of:
- `TOPIC_DIRECTORY_ONLY` — a research subject or ambition, never a runnable tool;
- `SOURCE_VERIFIED` — actual source/doc inspection, not deployment;
- `RELEASED_TOOL` — requires an exact, current, publicly demonstrable release and permissions;
- `FUTURE_GATED` — concept/prototype with documented blockers;
- `UNKNOWN` — no safe assertion.

The atlas JSON intentionally grants **no authority** and makes no claims of tool availability. Later authorized ingestion should add relationship edges between subject, places, projects, sources, ecosystems, animals, researchers, agent roles, verified tools, media and receipts only with provenance. Do not expose owner-private identity, location, assets or internal topology.

For 3D/XR, render the *same* subject IDs as navigable sectors in the future Gate 3 World. Maintain a lightweight 2D mode for phones, low-end devices and accessibility. A globe must never substitute illustrative pins for authentic real-time telemetry.

## Search discoverability and entity legitimacy

- Preserve the full **©️8x8 by FlashTM8** brand on public pages, with accurate Organization/CollectionPage structured data. Avoid confusing unrelated products named "8x8" with our project.
- Publish clear titles, headings, descriptions, links, authored explanations and relevant examples for actual subject matter. Use a consistent single canonical production domain only after the deployed route and control of the domain have been independently verified.
- The atlas has one substantive, browsable HTML page with 64 real anchors. **Do not create 64 near-duplicate keyword pages, thousands of dictionary doorway pages or scraped content**. An individual topic deserves its own indexable page only after original, useful, correctly sourced material or a genuine working user experience exists.
- Include XML sitemap and `robots.txt` references when the public canonical hostname and production release are accepted; do not publish guessed canonical URLs. Verify published sitemap and page availability from public HTTP, then submit through an authorized Search Console property. A sitemap submission is a hint, not a promise of indexing.
- Scientific, environmental, animal care, health, nuclear-energy, legal and finance pages need appropriate authoritative citations, review and clear non-professional/educational limits; no unsupported diagnosis, hazardous instructions, investment guarantees or real-time measurement claims.
- Where videos, images and originals have verified rights, use accurate descriptive text, captions, transcripts and appropriate structured data. Respect platform-specific policies, consent, citation and canonical URLs. No fake engagement, rank manipulation or spam.
- Connect real cross-carrier sources: canonical public site, Wix information discovery (after cross-domain truth review), actual approved ChatGPT MCP and skills listings, Telegram/Discord, Android/iOS releases and GitHub readme, with signed deployment/capability proof per carrier.

Official reference (reviewed 2026-11-01):
- Google Search Central, people-first content: https://developers.google.com/search/docs/fundamentals/creating-helpful-content
- Google Search Central, XML sitemap and canonical URL rules: https://developers.google.com/search/docs/crawling-indexing/sitemaps/build-sitemap

## Search → One Fabric path, proposed acceptance

Search topic/query → canonical public result → HTML subject directory → relevant cited overview or verified tool → tenant-specific 8x8 ID (only if the action actually requires authentication) → permissioned FlashTM8 Agent capability → real artifact → independent evidence → option to continue in World/Studio/on device. Topic search never triggers automatic device actions or paid transactions. For ordinary research, guest reading should require no login.

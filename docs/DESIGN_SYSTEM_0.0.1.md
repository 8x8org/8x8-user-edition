# 8x8 OS Visual System 0.0.1

**Product maturity:** 0.0.1 Beta  
**Reality:** PUBLIC_PRESENT  
**Status:** Design contract for the public-safe Fabric Mirror.

## Objective

The public interface must feel like an operating system and command fabric, not a generic landing page. The visual direction is derived from the approved 8x8 reference set: dense command-center instrumentation, multi-agent collaboration, neon spatial layers, world-scale telemetry, system maps, operator HUDs, and a clear red/cyan/violet 8x8 identity.

## Design principles

1. **Command center, not brochure.** The first viewport exposes system architecture, reality state, evidence state, and primary navigation.
2. **Dense but legible.** Information-rich panels use hierarchy, grouping, compact labels, and responsive collapse rather than decorative emptiness.
3. **Truth before spectacle.** Public panels distinguish VERIFIED, PARTIAL, PLANNED, BLOCKED, and PRIVATE. No decorative metric may impersonate live telemetry.
4. **Three Realities are structural.** Private Past, Public Present, and Future Lab remain visible as first-class system state.
5. **Agent civilization is visible.** The interface shows councils, model fabric, mission fabric, memory/evidence, devices, connectors, Studio, research, economy/testnet, and deployment as connected systems.
6. **8x8 visual DNA.** Dark base, luminous cyan/violet system lines, guarded red/orange identity accents, glass panels, grid overlays, orbital geometry, and restrained motion.
7. **Mobile is a cockpit.** On phones the experience becomes a vertical operator console with sticky command navigation rather than a reduced marketing page.
8. **Accessibility remains mandatory.** Contrast, keyboard focus, reduced-motion support, semantic sections, and readable type win over visual excess.

## Status language

- `VERIFIED`: directly backed by current public-safe evidence.
- `PARTIAL`: some evidence exists, but the complete capability is not certified.
- `PLANNED`: design or Future-Lab direction only.
- `BLOCKED`: known evidence gate or dependency is unresolved.
- `PRIVATE`: intentionally not projected publicly.

## Version rule

The product remains **8x8 OS 0.0.1 Beta**. Historical implementation generations, mission IDs, PRs, service generations, and internal revisions are not product maturity versions.

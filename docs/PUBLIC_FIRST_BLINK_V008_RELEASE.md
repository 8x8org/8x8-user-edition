# 8x8 User Edition — First Blink Fabric Mirror

Status: `SOURCE_READY / PUBLIC_DEPLOYMENT_REBIND_REQUIRED / UNIVERSAL_RUNTIME_CERTIFICATION_PENDING`

This release supersedes the tiny standalone First Blink preview approach. The public User Edition now treats the Fabric itself as the interface and First Blink as one gateway into a whole-system public-safe Reality Graph.

## What changed

- the repository root becomes the canonical public spatial cockpit rather than a separate novelty page;
- `/first-blink` resolves into the same whole-system interface;
- explicit mobile-safe HTML routing is defined for Vercel-compatible deployments;
- the interface includes the public-safe domains for agents, devices, projects, model routing, missions, evidence, Studio/media, channels/community, trading research, blockchain/economy research, security, release state and the spatial world;
- Private Past / Public Present / Future Lab are first-class temporal projections;
- First Blink exposes the context-bootstrap sequence and receipt requirement;
- visual-state labels remain evidence-gated.

## Deployment incident this supersedes

A prior preview was generated from an external ecosystem repository and was not a stable public front door. Cross-device tests reported that it could not be opened normally from Android and iPhone browsers. The preview also depended on protected deployment behavior. That deployment must not be treated as the canonical User Edition.

The repaired source belongs in `8x8org/8x8-user-edition`. Public deployment must bind to this repository and exact reviewed head, then prove normal browser behavior from at least mobile Safari and Android Chromium before promotion.

## Required public deployment checks

1. deployment is bound to the exact User Edition commit;
2. `/`, `/first-blink`, `/world` and `/art-board` return browser-renderable HTML;
3. `Content-Type` resolves to `text/html` for the root document and no `attachment` disposition is emitted;
4. logged-out access succeeds without preview authentication;
5. Android Chromium smoke passes;
6. mobile Safari smoke passes;
7. public-information boundary validation passes;
8. security headers and CSP pass;
9. no private topology, credential, wallet material, private message or privileged control path is published;
10. rollback target and release receipt are recorded.

## What this does not prove

It does not prove universal First Blink rehydration across every model/client call, complete 123+ fleet certification, closed-loop voice, live financial execution, unrestricted private-runtime mirroring or whole-system completion. Those remain separate evidence gates.

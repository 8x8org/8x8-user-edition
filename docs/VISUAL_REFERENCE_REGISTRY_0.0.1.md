## Extracted design grammar

The public 8x8 interface should combine the strongest recurring motifs without fabricating telemetry:

- dense command-center composition;
- a visually dominant 8x8 core;
- orbiting capability systems around the core;
- explicit agent and council topology;
- compact operational panels instead of brochure whitespace;
- cyan/violet information layers with restrained red/orange identity accents;
- world, map, mission, memory, Studio, research and economy surfaces;
- desktop command deck with a deliberate mobile cockpit collapse;
- clear separation of actual status from decorative visual instrumentation.
